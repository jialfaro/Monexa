# 1. Petición inicial (retorna HTTP 402 con requisitos de pago y contrato USDC)
curl -i -X POST https://swaziland-choice-minutes-alfred.trycloudflare.com/x402/smart-contract-audit \
  -H "Content-Type: application/json" \
  -d '{"contract": "pragma solidity ^0.8.0; contract Vault { mapping(address => uint) public balances; function withdraw() public { (bool s, ) = msg.sender.call{value: balances[msg.sender]}(""); balances[msg.sender] = 0; } }"}'

# 2. Petición con firma de autorización (HTTP 200 con resultado verificado)
curl -X POST https://swaziland-choice-minutes-alfred.trycloudflare.com/x402/smart-contract-audit \
  -H "Content-Type: application/json" \
  -H "PAYMENT-SIGNATURE: <PAYMENT_PAYLOAD_BASE64>" \
  -d '{"contract": "pragma solidity ^0.8.0; contract Vault { ... }"}'
TypeScript con @x402/fetch y @x402/evm 
import { wrapFetchWithPaymentFromConfig } from "@x402/fetch";
import { ExactEvmScheme } from "@x402/evm";
import { privateKeyToAccount } from "viem/accounts";

// Configura la cuenta del agente que paga en USDC (Base)
const account = privateKeyToAccount(process.env.AGENT_PRIVATE_KEY);

const fetchWithPayment = wrapFetchWithPaymentFromConfig(fetch, {
  schemes: [
    {
      network: "eip155:8453", // Base Mainnet
      client: new ExactEvmScheme(account),
    },
  ],
});

// Llamada transparente: el wrapper intercepta el 402, firma y liquida en USDC
const response = await fetchWithPayment(
  "https://swaziland-choice-minutes-alfred.trycloudflare.com/x402/smart-contract-audit",
  {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      contract: "pragma solidity ^0.8.0; contract Vault { ... }"
    })
  }
);

const auditReport = await response.json();
console.log("Hallazgos de seguridad:", auditReport.findings);
Python para Agentes Autónomos (LangChain / AutoGen / CrewAI) 
import requests
import base64
import json
from eth_account import Account
from eth_account.messages import encode_typed_data

# URL del servicio Monexa
ENDPOINT = "https://swaziland-choice-minutes-alfred.trycloudflare.com/x402/unit-test-gen"
payload_data = {"code": "function add(a, b) { return a + b; }", "framework": "jest"}

# 1. Petición sin pago para obtener requisitos
r = requests.post(ENDPOINT, json=payload_data)
if r.status_code == 402:
    req_header = r.headers.get("PAYMENT-REQUIRED")
    requirements = json.loads(base64.b64decode(req_header).decode("utf-8"))
    accept = requirements["accepts"][0]
    print(f"Pago requerido: {int(accept['amount'])/1e6} USDC a {accept['payTo']} en Base")

¿Cómo funciona la liquidación sin custodia?

1

Desafío HTTP 402

El cliente o agente envía su petición. El servidor devuelve HTTP 402 con los requisitos exactos de la red Base y el contrato de USDC.

2

Firma Criptográfica

El cliente firma una autorización EIP-3009 en su wallet o agente. El servidor de Monexa nunca toca ni almacena claves privadas.

3

Liquidación Instantánea

El facilitador PayAI liquida la transferencia on-chain hacia la wallet configurada y la IA ejecuta el análisis de alta velocidad.
